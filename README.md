# Telegram Download Bot

Send a YouTube, TikTok or Instagram link to the bot on Telegram and it downloads the video and sends it back (max 50 MB, Telegram Bot API limit).

Run with `python main.py`. Requires `BOT_TOKEN` environment variable.
Flask keep-alive on `/` and `/health`.
